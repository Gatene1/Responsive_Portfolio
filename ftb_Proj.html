About This Project

Glean's First isometric arcade-style game, set in a single bar where drinking, social interactions, and buttefly-chasing drive the night.

Core Features

  • Classic collectable gathering gameplay
  • Dynamic one-stage design
  • Night-by-night progression with changing bar configurations

Built With

  • JavaScript + HTML5 Canvas
  • Custom engine vibe coded with multiple AI sources

Status: In active development
