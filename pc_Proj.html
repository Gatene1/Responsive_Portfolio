About This Project

PatternChooser is an interactive design companion that helps developers identify and contrast core gameplay patterns.

Still in development!

Core Features

  • Pattern Cards
  • Save Stack (Scrapbook Fan)
  • Randomized Inspiration

Built With

  • JavaScript + HTML5 Canvas
