The Adventures of Mr. Pillbody's Showcase

Unreal Engine Blueprints

BPC_MrPillbody
This is my blueprint for the Player character, Mr. Pillbody. The actual combat comes from the IA_Attack node.
WeaponHolstered?
This function is part of the combat system to tell if the Player can swing his sword by finding out if he's already attacking, finishing up, or if the sword is holstered (on his side). If it is the latter, the player can swing his sword to attack.
AdvanceSwordAttackTypeEnum
This function is part of the combat system to tell which type of sword attack the Player will execute when pressing LMB or 'E'. There are only 2 types now: a standard hack (straight up and down rotation), and the secondary one that swings the sword laterally directly in front of the Player, causing a further reach.
BPC_Nobody
This blueprint is the blueprint for the enemy character, "Nobody". For the Event Dispatcher, I didn't want to overcrowd Even BeginPlay, so I made a second custom event, which is toward the bottom of this same blueprint.
CanAttack?
This is a blueprint that is part of the combat system to see if the enemy can attack the player when he's in the appropriate state.
Comp_HP
This is the main blueprint for the Comp_HP component that governs HP in the characters. Be sure to CTRL+Scroll out to see the second event at the bottom.
AdjustHP
This function is part of the combat system, and as its name suggests, a value (postive or negative) is added to the current HP, is clamped, and sent back to the caller.
UpdateCharacterHPWidget
this function is part of the combat system inside the Comp_HP component to update HP bar on either the Player or the Enemy with the World Space Widget for the health bar.
SetHealth
This function is inside the W_HPBar widget that is used for both players: a front-facing local-space health bar using the widget for the Player, and a world-space health bar using the widget for the enemy. This function updates the Percentage of the progress bar.
